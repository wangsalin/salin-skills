## 一、黄金 3 秒：开头留人的底层逻辑

### 1.1 为什么前 3 秒决定生死

- 用户刷到一条视频的平均停留判断时间约 3 秒，多数用户在第 3 秒前决定划走还是留下。
- 平台推荐是"流量池逐级放大"逻辑：视频先进小流量池（几百播放），依据 **5 秒完播率、整体完播率、互动率、转粉率**决定是否推入下一级流量池，其中完播率权重最高——开头留不住人，后面拍得再好也没机会被看到。
- 结论：**开头不是视频的一部分，开头是视频的门票。** 脚本创作顺序应该是：先定转化目标 → 再写钩子 → 最后填中间内容。

### 1.2 开头五大形式（含门店化例句）

| 形式 | 底层心理 | 万能公式 | 门店例句 |
|---|---|---|---|
| **提问式** | 被点名感、痛点共鸣 | 「为什么你 + 痛点现状？」 | 健身：「为什么你天天跑步，肚子就是下不去？」美发：「为什么你染的发色，出门三天就土了？」 |
| **冲突/反常识式** | 认知失调，想看解释 | 「千万别 + 大家都在做的事」 | 餐饮：「我劝你别在下午 5 点来我们店，真的排不上。」教培：「千万别一上来就给孩子报一对一，钱多半白花。」 |
| **悬念式** | 好奇心缺口 | 「最后一个 XX 惊到我了」 | 探店：「这家店开在巷子最里面，没招牌，但每天中午要排 40 分钟。」 |
| **利益点前置式** | 占便宜、怕错过 | 「XX 元搞定 XX」 | 团购：「99 块，四个人吃到扶墙出，就在 XX 路。」美容：「这条视频帮你省下 2000 块的智商税。」 |
| **视觉冲击式** | 感官刺激，无需思考 | 高潮画面前置 | 餐饮：起锅浇油的爆响特写开场；美发：直接放"素人进店→换头出门"对比图 |

### 1.3 开头设计三条铁律

1. **视觉钩子 > 文字钩子。** 说"月瘦 10 斤"不如直接放对比图；说"芝士拉丝"不如给拉丝特写。能用画面说的不用嘴说。
2. **钩子必须兑现。** 开头承诺什么，视频里必须给什么，否则完播率高、转化为零，还掉粉。钩子是"提前剧透最精彩的部分"，不是骗点击。
3. **一题多钩，测试定稿。** 同一条内容拍 3 版不同开头，各投 100 元小额 DOU+，看 5 秒完播率数据，保留最好的一版作为该系列固定模板。

### 1.4 门店向钩子句式补充

（通用八类钩子话术库见 hooks.md，此处为门店 IP 向补充）

- 「在 XX（城市/商圈）待了 X 年，这家店我藏不住了」
- 「做 XX 行业 X 年，今天说句得罪同行的话」
- 「顾客问我最多的一个问题就是……」
- 「这条视频只有本地人能刷到」
- 「别再花冤枉钱做 XX 了」
- 「今天店里发生了一件事，我必须说说」
- 「如果你也 XX（痛点行为），这条视频先别划」
- 「我把成本表拍给你看」
- 「99% 的人第一步就做错了」
- 「先看效果，再听我说」（先放结果画面）

## 二、常见脚本结构：6 套框架与适用场景

### 2.1 三段式：钩子—内容—转化（万能默认结构）

```
【钩子】0-3s        一句话/一个画面留住人
【内容】3s-结尾前    兑现钩子承诺：干货/过程/故事
【转化】最后3-5s     一个明确动作指令（CTA）
```
设计要点："**两头重、中间轻**"——开头负责留人、结尾负责转化，中间内容不要复杂难懂，观众是躺着刷手机的。拿不准就用它。

### 2.2 时间轴框架（60 秒口播/带货标准节拍）

```
0-3s    开场钩子（痛点/悬念/利益点）
3-15s   问题/冲突展开（放大痛点，让观众对号入座）
15-45s  解决方案/过程展示/反转（视频主体）
45-60s  行动号召（关注/评论/点团购/到店）
```

### 2.3 SCQA：情境—冲突—疑问—答案

经典案例即"得了灰指甲（S），一个传染俩（C），问我怎么办（Q），马上用亮甲（A）"。

| 环节 | 作用 | 教培门店示例 |
|---|---|---|
| S 情境 | 熟悉场景引入，产生代入 | 「孩子每天作业写到 11 点」 |
| C 冲突 | 现实与期望的落差 | 「时间花了不少，成绩就是不动」 |
| Q 疑问 | 替观众问出心里话 | 「问题到底出在哪？」 |
| A 答案 | 给方案（即你的专业/服务） | 「不是不努力，是方法错了，三步教你判断……」 |

适合：**口播干货、老板 IP 讲观点、专业人设**（美业皮肤科普、健身知识、教培方法论）。

### 2.4 AIDA：注意—兴趣—欲望—行动

```
A 注意：钩子开场（前3秒）
I 兴趣：展示与"我"相关的信息（这家店/这个套餐和我有什么关系）
D 欲望：细节刺激（菜品特写、效果对比、顾客见证、限量限时）
A 行动：明确指令（点左下角团购/评论扣1/到店报暗号）
```
适合：**团购推广、促销活动、新品上市**。

### 2.5 痛点—放大—方案—行动（服务业最强结构）

心理学依据：人逃避痛苦的行动力远强于追求快乐。注意：放大痛苦后必须立刻给方案，否则就是贩卖焦虑。

```
【痛点】说出目标客户正在经历的具体麻烦（越具体越扎心）
【放大】不解决的后果/继续错下去的代价
【方案】你的服务如何解决 + 证据（过程/案例/对比）
【行动】现在就能做的低门槛动作
```
门店示例（美发）：「烫完头三天就塌，是不是你？」→「不是你头发的问题，是药水和手法不匹配，再烫两次发质就废了」→「先做发质检测再定方案，看这位姐烫完第 15 天的实拍」→「评论区扣『检测』，到店免费测发质」。

适合：**美业、健身、教培、维修类**等"解决问题型"服务。

### 2.6 故事弧与 358 节奏

**故事弧**（创业故事、剧情段子、顾客故事）：
```
起：日常状态（铺垫，建立预期）
承：意外/冲突出现（打破预期）
转：反转或转折（最大情绪点）
合：结局 + 价值升华（带出人设或门店卖点）
```

**358 框架**（节奏快的娱乐向内容）：**3 秒吸睛、5 秒讲清痛点、每 8 秒一个亮点或反转**，防止任何一段变平。

### 2.7 结构选型对照表

| 视频类型 | 首选结构 | 备选 |
|---|---|---|
| 探店种草 | 三段式 / AIDA | 时间轴框架 |
| 老板 IP 讲干货/观点 | SCQA | 三段式（清单体） |
| 老板创业故事 | 故事弧 | SCQA |
| 团购促销 | AIDA | 痛点—放大—方案—行动 |
| 服务效果类（美业/健身/教培） | 痛点—放大—方案—行动 | SCQA |
| 剧情段子 | 故事弧 + 358 节奏 | — |
| 过程实拍/沉浸式 | 三段式（弱化口播） | — |

## 三、分镜脚本表：标准格式

### 3.1 标准字段

完整分镜表按 **镜号 / 景别 / 运镜 / 画面内容 / 台词(口播) / 字幕 / 时长 / BGM及音效** 组织，可按需增加"道具、机位、演员、备注"列。景别运镜的具体拍法见 shooting.md。

### 3.2 完整示例：25 秒餐饮团购视频分镜

| 镜号 | 景别 | 运镜 | 画面内容 | 台词/口播 | 字幕 | 时长 | BGM/音效 |
|---|---|---|---|---|---|---|---|
| 1 | 特写 | 固定 | 红油锅底沸腾冒泡，牛油下锅 | 「在 XX 路吃火锅，人均 50 真吃不到这种货。」 | 人均50？ | 3s | 咕嘟声原声，BGM 弱起 |
| 2 | 中景 | 跟 | 服务员端锅上桌，穿过热闹大堂 | 「这家店开了 8 年，老板只认一件事——」 | 开了8年的老店 | 4s | BGM 进入 |
| 3 | 特写 | 推 | 手切鲜牛肉纹理，筷子夹起抖动 | 「牛肉每天早上现切，冻货一律不进门。」 | 每日现切 | 4s | 原声+BGM |
| 4 | 近景 | 固定 | 顾客涮肉入口，点头 | （顾客原声）「比我在 XX 吃的嫩多了。」 | 真实顾客 | 3s | 原声 |
| 5 | 特写 | 固定 | 菜品逐样快闪：虾滑/毛肚/鸭血 | 「四人餐：鲜牛肉、虾滑、毛肚 12 个菜——」 | 12道菜快闪报菜名 | 5s | 节奏卡点 |
| 6 | 中景 | 拉 | 满桌全貌，四人举杯 | 「原价 328，今天团购 198。」 | 328→198 | 3s | BGM 高潮 |
| 7 | 近景 | 固定 | 老板对镜头指左下角 | 「链接就挂在左下角，本周有效，吃完不满意来找我。」 | 点左下角↓ 仅限本周 | 3s | BGM 收尾 |

实操提示：单人小店不必每条都写全表。**口播类只写"台词+画面提示"两栏；剧情类和探店必须写全表**，否则现场拍摄效率极低。先写台词列，再倒推画面列。

## 四、口播稿写法

### 4.1 语速与字数对应（写稿前先定时长）

| 场景 | 语速 | 说明 |
|---|---|---|
| 日常说话/慢节奏 | 约 200-240 字/分钟（3.5-4 字/秒） | 面向中老年客群建议用这档 |
| **抖音口播推荐** | **300-360 字/分钟（5-6 字/秒）** | 短视频用户习惯高密度快节奏，可写正常稿后加 1.1-1.2 倍速 |

**时长-字数速查**：15 秒 ≈ 75-90 字；30 秒 ≈ 150-180 字；60 秒 ≈ 300-360 字。**写完稿先朗读计时，超时先删字，不要硬加语速。**

### 4.2 口语化改写六个技巧

1. **删书面连接词**：删掉「不但/而且/既能/又能/综上所述/首先其次再次」，换成「而且/还有/最关键的是/说白了」。
2. **短句化**：一句话不超过 15 字，一口气能说完。长句拆成两句。
3. **人称对话感**：多用「你」；想象对着一个熟客说话，不是对着镜头念稿。
4. **每句只装一个信息点**：一句话塞两个信息，观众一个都记不住。
5. **先抛问题再给答案**：口语习惯是"你知道为什么吗？因为……"，不是"原因有三点如下"。
6. **念稿测试**：写完大声读三遍，任何读着别扭、需要换气两次的句子，一律重写。

**改写示例**：
> 书面版：「本店采用进口设备与资深技师团队，能够为顾客提供专业且舒适的护理体验。」
> 口播版：「你躺下来那 40 分钟，手法、仪器、房间温度，我们都替你调好了。做完你自己照镜子。」

### 4.3 节奏设计

- **每 2-3 秒一个信息点**完成"画面+文案"双重传达；同一件事讲超过 5 秒、画面还静止，就是拖沓，必剪。
- 重点句前留 0.5 秒停顿、放慢、加重音，同时上大字字幕——"慢"本身就是强调。
- 段落之间用口语衔接词换气：「注意了」「重点来了」「说个大实话」。

## 五、台词写作：衔接话术与 CTA 设计

### 5.1 钩子 → 干货的衔接话术（3 秒后不冷场）

- 「别急着划，我一条条给你说。」
- 「这事我踩过坑，所以你听我的。」
- 「先说结论：……为什么？」
- 「我直接拍给你看。」（转入实拍画面）
- 「做这行 X 年，就总结出这三条。」

### 5.2 干货 → 转化的衔接话术（不生硬地进广告）

- 「说这么多，其实就是我们店每天在做的事。」
- 「如果你懒得自己弄，来店里 20 分钟给你搞定。」
- 「方法就是这个方法，差别在手上功夫——不信你来看一次。」
- 「这个东西线上说不清楚，你到店我当面给你看。」

### 5.3 结尾 CTA：按目标分层设计

**原则：一条视频只主推一个动作**；CTA 至少出现 2 次（口播一次 + 字幕/贴纸强化一次）；动作要具体、低门槛、最好绑一个即时好处。

| 目标 | 话术模板 |
|---|---|
| **关注** | 「关注我，每周三教你一个在家就能做的 XX。」（给持续价值理由，不说"求关注"） |
| **评论** | 「你遇到过最离谱的 XX 是什么？评论区聊聊。」/「想要 XX 攻略的，评论区扣 1。」 |
| **点团购** | 「套餐就挂在左下角，X 号之前都有效，先囤后约。」 |
| **到店** | 「到店报暗号『刷到你了』，送 XX / 减 X 元。」（暗号还能统计视频到店效果） |
| **收藏** | 「信息量有点大，先收藏，到店前拿出来照着点。」 |
| **私信/咨询** | 「不确定自己适不适合的，私信发我照片，我免费帮你看。」 |

## 六、完播与互动设计

### 6.1 中段防划走五招

1. **高信息密度**：每 2-3 秒换一个信息点，每 5-10 秒抛一个爆点/反转/新画面。
2. **画面强制刷新**：同机位不超过 5 秒——切景别、换机位、插大字卡、加音效、变速，都算刷新。
3. **进度承诺**：「一共 5 个，**最后一个最狠**」「第三点 90% 的人都做错」——给观众看到最后的理由。
4. **钩子回收**：开头挖的坑（悬念）放到最后一秒才填，中途只给线索不给答案。
5. **时间压力话术**：「10 秒教会你」「直接跳到成品」——明示不浪费时间。

### 6.2 视频内埋互动点

| 类型 | 做法 | 门店示例 |
|---|---|---|
| 提问式 | 视频中途/结尾抛具体问题 | 「你们觉得这碗面卖 18 贵吗？」 |
| 争议式 | 抛一个两派都有理的观点 | 「健身房私教到底值不值得买？」「剪发到底该不该先洗头？」 |
| 投票式 | 二选一降低参与门槛 | 「A 款和 B 款发色，评论区选一个，选的人多的下周教程安排。」 |
| 找茬式 | 故意留个小瑕疵/口误 | 评论区必有人纠正，互动自然起量（慎用，别伤专业人设） |
| 征集式 | 邀请分享经历 | 「你在理发店听过最吓人的推销是什么？」 |

### 6.3 评论区运营钩子

- **置顶评论 = 第二转化位**：放地址、营业时间、团购入口、暗号福利。
- **预埋评论**：发布后用小号/熟客预埋约 3 条方向性评论（一条质疑、一条调侃、一条提问），引导讨论走向。
- **回复带新问题**：回复粉丝时结尾再抛一个问题，把单次互动变成对话串。
- 差评冷静回、恶意的删，建设性批评公开认——评论区态度本身就是门店人设。

### 6.4 收藏与转发话术

- 收藏（针对攻略/清单/干货）：「怕你到时候找不到，先收藏。」「点菜攻略都在这条里，进店前翻出来。」
- 转发（绑定具体关系人）：「把这条发给那个天天说要减肥的朋友。」「@ 一下周末要来 XX 逛街的搭子。」——转发指令越具体，执行率越高。

## 七、门店六大视频类型：脚本套路模板

### 7.1 探店 / 第三视角种草

以"顾客视角"建立信任，可自拍（员工/朋友扮演顾客）或请达人拍。**达人脚本核心只有三句话：卖点一句、适合谁一句、到店怎么用一句。**

```
结构模板（30-45s）：
0-3s   钩子：位置反差/排队盛况/价格冲击（「藏在写字楼 7 楼的理发店，想剪要提前 3 天约」）
3-8s   进店第一印象：环境快剪 + 一句定位（「主打一个安静，没人给你推销」）
8-25s  体验主体：2-3 个核心卖点，每个=特写画面+一句评价
25-35s 价格与适合谁：「人均 XX」「适合 XX 的人」「XX 慎点」（小缺点反而加真实感）
35-45s 转化：位置+团购+到店建议（「导航搜 XX，记得避开饭点」）
```
**加分技巧**：说一个无伤大雅的缺点（「停车确实难，建议地铁」），种草可信度大幅提升。

### 7.2 老板 IP 口播（创业故事 / 行业干货 / 避坑）

人设公式：**经历 + 故事 + 性格 + 理念 + 理想**。切记：**用户爱听故事和"内幕"，不爱听教材**——干货要包在故事和冲突里讲。

```
A. 创业故事（故事弧）：
「XX 年我从 XX 辞职开了这家店（起）→ 第 X 个月差点关门/被骗/亏到 XX（承）
→ 一件事让我想通了/一个老顾客的一句话（转）→ 现在我只坚持 XX，这也是这家店的规矩（合）」

B. 行业干货（清单体三段式）：
「做 XX 十年，教你 3 招不花钱就能 XX（钩子）→ 第一…第二…第三，
最后一个最重要（内容，每点配实拍画面）→ 关注我，下期讲 XX（转化）」

C. 行业避坑（冲突开头 + SCQA）：
「今天说句得罪同行的话（钩子）→ 你去 XX 店常遇到 XX（S）→ 其实那是套路，
成本才 XX（C）→ 那怎么判断？（Q）→ 记住这两点…我店里从来只 XX（A+人设）」
```
**频率建议**：故事类一周 1 条立人设，干货/避坑一周 2-3 条撑流量。

### 7.3 产品/服务实拍（过程满足类）

利用"沉浸式"心理：**原声大于 BGM**（剪刀声、煎炸声、器械声自带解压属性），过程完整、动作特写，弱口播甚至零口播。

```
结构模板（15-40s）：
0-3s   成品/最高潮画面前置（拉丝、出炉、换头对比）
3-30s  过程快剪：按真实工序推进，每道工序 2-4 秒特写，保留原声
       中途插 1-2 张字卡交代关键信息（「低温慢烤 4 小时」「只用当天鲜奶」）
最后5s 成品定格 + 一句转化字幕（「每天 14:00 出炉，卖完即止」）
```
适合：烘焙/炒菜/摆盘、剪发染发全过程、美甲美睫、皮肤管理、健身动作教学。**这是拍摄门槛最低、最不挑出镜能力的类型，新账号建议从它起步。**

### 7.4 剧情段子类（前厅后厨 / 顾客互动）

核心公式：**日常铺垫 → 冲突 → 意外反转 → 反转里藏卖点**。卖点必须是反转的一部分，而不是结尾硬贴。

```
结构模板（20-40s，参考 358 节奏）：
0-3s   冲突直接开场（顾客拍桌：「你们这肉是不是不新鲜！」）
3-15s  冲突升级/误会加深（老板不辩解，转身进后厨……）
15-25s 反转（端出整扇现切排骨：「姐，今天的猪 6 点才到的，您指哪块我切哪块」）
最后5s 收尾梗 + 卖点字幕（顾客：「……那再加两斤。」字幕：每日鲜肉 6 点到店）
```
**门店常用剧情母题**：顾客砍价、奇葩要求、新员工闯祸、老板抠门（实际对顾客大方）、同行探底、前厅后厨互怼。一个母题可以系列化，养成连续剧追更效果。

### 7.5 促销活动 / 团购推广

```
结构模板（AIDA，20-30s）：
0-3s   利益点砸脸：「198 吃原价 328 的四人餐，就这周。」
3-15s  套餐可视化：逐样快闪报菜名/服务项目，配特写（观众要"看见"自己买到什么）
15-22s 价格锚点+限制条件：「原价 XX→现价 XX」「仅 X 天/仅 X 份/新客专享」
22-30s 行动指令：「点左下角先囤后约，到期可退」+ 到店提示（地址/预约方式/避峰建议）
```
**运营配套**：推团购期间围绕套餐持续输出（日更 1-3 条不同角度：菜品/环境/顾客角度）；盯三个数据——曝光转化率、核销率、退款原因。达人视频负责"信任"，门店自己的账号负责"承接"（停车、预约、真实流程细节）。

### 7.6 员工 / 日常 vlog 类（职人视角）

"职人网红"逻辑：以真实工作日常建立亲近感与信任。

```
结构模板（30-60s）：
0-3s   身份+悬念钩子：「在火锅店切了 8 年肉，今天带你看我一天。」
3-40s  时间线快剪：开店准备→高峰名场面→幕后细节（备货量、卫生流程、员工餐）
       每段 3-5 秒 + 一句旁白/字幕，埋 1 个小冲突或趣事
40-60s 收尾感悟一句（不煽情过度）+ 轻转化（「明天想看后厨还是前厅？评论区说」）
```
适合：想做长期账号但老板不愿出镜的门店；重点是**真实**——过度摆拍的"日常"观众一眼识破。

### 7.7 起步选型建议

| 门店情况 | 首选类型 | 原因 |
|---|---|---|
| 没人愿出镜、没预算 | 过程实拍 + 员工 vlog | 拍摄门槛最低，原声即内容 |
| 老板能说、有故事 | 老板 IP 口播 | 人设复利最高，转化信任最强 |
| 有活动要冲销量 | 团购推广 + 探店 | 转化链路最短 |
| 员工年轻、有梗 | 剧情段子 | 涨粉最快，但转化需另设计 |

## 八、标题与封面

### 8.1 标题文案：和口播钩子是两个工种

- **口播钩子**对"已经开始播放的人"负责（留人）；**标题**对两类对象负责：给**算法和搜索**喂关键词（行业词+同城词），给**刷到但还没入戏的人**第二个停下的理由。
- 因此：**标题不要复读口播第一句**。口播抛悬念，标题就补信息（地点/价格/人群）；口播讲信息，标题就加悬念或情绪。
- 同城门店标题里尽量带：**城市/商圈/路名 + 品类词**（如「#长沙探店 #五一广场美食」），有助进入同城流量池与搜索流量。

**标题句式库（门店向）**：
1. 疑问式：「XX 路这家开了 10 年的粉店，凭什么天天排队？」
2. 悬念式：「没想到央视都报道过的手艺，就藏在我们小区门口」
3. 数字式：「30 块吃 3 个菜，XX 打工人的食堂被我找到了」
4. 人群点名式：「XX 的宝妈看过来，孩子写作业磨蹭一定要试这招」
5. 反常识式：「开理发店的劝你别办卡？」
6. 本地情绪式：「XX 人才懂的一口，外地朋友别跟我抢」
7. 攻略收藏式：「XX 商圈遛娃半日路线，直接抄作业」
8. 福利式：「评论区扣 1，送 XX（限同城）」

### 8.2 封面图三要素

1. **大字标题**：不超过 2 行，字号大、颜色与背景强对比；主标一句抓眼 + 副标补充信息（价格/地点）。系列内容用统一字体和排版，主页看起来像一个专栏。
2. **清晰主体（人脸或产品）**：有情绪的人脸最抓眼（惊讶/大笑/皱眉）；产品图选最高食欲/效果值的一帧。注意安全区：别让播放按钮压脸、别让边框裁切文字。
3. **可视化的价值点**：**前后对比图**（美业/健身最强武器）、**价格数字**（328→198）、**结果画面**（成品/满座/排队）。让人 1 秒看懂"点进来能得到什么"。

组合公式：**情绪人脸/高潮画面 + 2 行大字（悬念或利益）+ 1 个数字（价格/时长/数量）**。同一账号固定封面模板，每周只换图和文字。
